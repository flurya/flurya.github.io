Problem 2B

If we are to turn the data frame that results from Problem 1A as a SharedData object, would $rank column be a good candidate to use as a key?

No, this is because rank is non-unique. Two or more universities can tie and thus have equal rank. So by using rank as a key, this could return multiple universities from a given rank.
